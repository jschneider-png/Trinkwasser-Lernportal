📤 PDF lokal auswählen

Damit kannst du im Browser testen, wie eine PDF dargestellt wird. Die Datei wird nicht ins Internet hochgeladen.

PDF

So kommen PDFs dauerhaft auf deine GitHub-Seite

  1. Im Repository einen Ordner pdf anlegen.
  2. Auf Add file → Upload files klicken.
  3. PDF hineinziehen und committen.
  4. Im HTML mit href="pdf/deine-datei.pdf" verlinken.

Wichtig: Auf einer normalen statischen GitHub-Pages-Seite können Schülerinnen und Schüler Dateien nicht dauerhaft auf den Server hochladen. Dafür bräuchtest du zusätzlich einen Upload-Dienst oder ein Backend.
