# Virtuelles Klassenzimmer – Blockwoche 1

Diese Version ist als kleine Homepage aufgebaut. Alle Navigationsbuttons sind mit Inhalt hinterlegt.

## Dateien
- `index.html` – Seitenstruktur
- `style.css` – Gestaltung
- `script.js` – Navigation, Lernmodule und Interaktionen
- `assets/klassenzimmer-vorlage.png` – die verwendete Abbildung
- `pdf/` – hier kommen deine PDF-Dateien hinein

## PDFs hinzufügen
Lege PDF-Dateien im Ordner `pdf/` ab. In der aktuellen Version sind diese Dateinamen bereits verlinkt:

- `arbeitsblatt-blockwoche1.pdf`
- `glossar-trinkwasser.pdf`
- `experiment-wasserhaerte.pdf`
- `merkkarte.pdf`

Du kannst die Dateinamen natürlich in `index.html` ändern.

### Upload in GitHub
1. Repository öffnen.
2. In den Ordner `pdf` wechseln.
3. **Add file → Upload files** auswählen.
4. PDF hineinziehen.
5. **Commit changes**.

Danach ist die PDF über GitHub Pages unter `pdf/dateiname.pdf` erreichbar.

## GitHub Pages
Unter **Settings → Pages**:
- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`
- Save

## Hinweis
Die lokale PDF-Auswahl auf der Seite ist nur eine Vorschau im Browser. Ein dauerhaftes Hochladen durch Besucher ist auf einer statischen GitHub-Pages-Seite ohne zusätzliches Backend nicht möglich.
